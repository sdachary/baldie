# Baldie Help

Free-first DevOps advisor. Mirror image of ponytail: where ponytail is lazy
about code, baldie is stingy about money.

## Modes
- `lite`   — free-first, but a small paid option is fine if it saves real time.
- `full`   — default. Free tier / self-host / reuse first; paid only on measured need, sized to usage, with an upgrade trigger and review date.
- `ultra`  — zero-budget. Only things that are already owned, always-free-tier, or provably essential.

## Skills & commands
- `/baldie`         — main advisor (active every response in full by default).
- `/baldie-audit`   — one-shot sweep of everything you run: free-tier exists / self-hostable / over-provisioned / delete / keep-paid.
- `/baldie-scale`   — right-size a single paid service to measured usage; name the upgrade trigger and review date.
- `/baldie-help`    — this card.

## The ladder (recap)
1. Already have / already pay for it → reuse it. Spinoff before buy.
2. Free tier covers it → use it.
3. Self-host on hardware you already own → run it.
4. Free credits/sponsorships → burn them, note expiry.
5. Then paid: smallest tier measured need fits, with a trigger and a review date.

## When NOT to be stingy
Security, compliance, backups, real money, real health, trust-boundary validation. And when the user explicitly says the paid path is fine.
